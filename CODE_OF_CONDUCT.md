# Code of conduct

FrameFusion follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good faith, and keep discussion about the work.
Harassment, personal attacks and sharing other people's private information are not accepted
in issues, pull requests or any other project space.

The maintainer ([@barkerbg001](https://github.com/barkerbg001)) may edit or remove comments,
close issues and pull requests, or block accounts that break these rules.

To report a problem, contact the maintainer through GitHub. The project does not yet have a
private conduct contact; if a report contains private details, say so in a minimal public issue
and ask to be contacted instead of posting them.
